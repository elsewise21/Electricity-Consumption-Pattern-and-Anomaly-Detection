# Electricity-Consumption-Pattern-and-Anomaly-Detection
Analyzed  historical electricity consumption observations across three distribution zones in Tetouan City, Morocco.
To investigate consumption patterns and compare statistical variation between zones
Identify anomalies while considering the limitations of statistical anomaly detection.

## Data used
UCI Machine Learning Repository:
Dataset name: Power Consumption of Tetouan City
Repository: UCI Machine Learning Repository
Dataset ID: 849
Link: https://archive.ics.uci.edu/dataset/849/power+consumption+of+tetouan+city
